# 구현 계획: 익명 이력서 평가와 버전별 평가 이력

작업 하나는 20~30분 크기다. 각 작업이 끝나면 `./gradlew test bootJar`를 실행한다. 병렬 표시가 있는 작업은 파일 경계가 달라 `spawn_run(tasks=[...])`로 동시에 돌릴 수 있다.
MVP 핵심은 이력서 마스킹과 익명 평가다(2026-11-14 사용자 결정). 확장 작업은 핵심·배포·녹화 준비가 끝난 뒤에만 시작한다.
컷 기준(05:30 UTC): 작업 1~7이 안 끝났으면 작업 10을 버전 목록과 평가 목록만으로 줄인다.
